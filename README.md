# Simon Game

A fun and interactive Simon memory game built using HTML, CSS, and JavaScript.

## About the Project

This project is part of my JavaScript and Web Development learning journey.

The game challenges players to remember and repeat a sequence of colored buttons. Each level adds another color to the sequence, increasing the difficulty.

## Features

- Interactive four-color game
- Random color sequences
- Level progression
- User input validation
- Game-over detection
- Score tracking
- Highest score tracking
- Animated button flashes
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Open the game.
2. Press any key to start.
3. Watch the button that flashes.
4. Click the buttons in the same sequence.
5. Repeat the sequence as it grows with each level.
6. If you select the wrong button, the game ends.
7. Try again and beat your highest score!
